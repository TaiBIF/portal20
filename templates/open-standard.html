{% trans "資料標準與模板" %}

在生物多樣性的領域，主要負責開發及維護資料標準的是{% trans "生物多樣性資訊標準" %}組織。 作為{% trans "國際生命科學聯盟" %}的附屬機構，該非營利的科學及教育協會專注於開發生物及生物多樣性資料的交換標準。 {% blocktrans %} 生物多樣性的社群成員一般將此組織稱為TDWG（音同 Tad-Wig），因其前身為分類學資料庫工作小組（Taxonomic Databases Working Group）。 {% endblocktrans %}

Darwin Core Standard {% trans "達爾文核心標準" %}(簡稱 DwC)，是目前國際通用的生物多樣性資料標準，也是TaiBIF和GBIF體系在推廣並提供的資料架構及概念。

Ecological Metadata Language {% trans "生態詮釋資料語言" %}（簡稱 EML），則是一種詮釋資料(metadata)規範。 {% trans "它使用一系列模組化、可擴展的 XML 文件類型來記錄生態資料集的資訊。 所有資料集的描述都依賴詮釋資料；" %} {% trans "也就是說，關於資料的資訊都使用此開源 EML 標準—它是由生物複雜性知識網絡所管理及維護。" %} {% trans "每個達爾文核心集資料檔案的組成部件中都包含一個 EML 文件（以XML 格式撰寫）。" %}
