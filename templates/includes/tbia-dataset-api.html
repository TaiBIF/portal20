可接受的查詢值 中文對照與說明
CC0 公眾領域貢獻宣告
CC-BY 創用 CC 姓名標示授權
CC-BY-NC 創用 CC 姓名標示－非商業性授權
NA 來源標示授權不明；不包含所有授權缺值。此值僅供查詢，回傳欄位不會出現字串 NA。

回傳欄位說明

名稱 類型 說明
datasetName 字串 資料集名稱。
datasetID 字串 TaiBIF 資料集的唯一識別碼（UUID）。
gbifDatasetID 字串 GBIF 資料集的唯一識別碼。
occurrenceCount 整數 資料集含括的紀錄總筆數。
resourceCitationIdentifier 字串 GBIF 資料集頁面的完整網址；沒有 GBIF 資料集 ID 時為 null。
datasetPublisher 字串 資料發布單位名稱。
datasetPublisherID 字串 資料發布單位的識別碼。
core 字串 資料集核心類型。控制詞彙：SAMPLINGEVENT（調查活動）、OCCURRENCE（出現紀錄）、CHECKLIST（物種名錄）、METADATA（僅詮釋資料）。
source 字串 資料集來源：TaiBIF IPT 或 GBIF。
datasetLicense 字串 資料集的授權方式。可能值：CC0（公眾領域貢獻宣告）、CC-BY（姓名標示）、CC-BY-NC（姓名標示－非商業性）。來源標示授權不明、未提供或尚無法辨識時回傳 null。
created 字串 資料集建立日期，臺灣時區，格式 YYYYMMDD。
modified 字串 資料集更新日期，臺灣時區，格式 YYYYMMDD。
