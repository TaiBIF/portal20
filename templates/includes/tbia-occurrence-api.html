時間資訊參數

名稱 備註 範例
modified 以資料解讀／處理日期查詢。格式 YYYYMMDD，區間以逗號分隔，包含起訖日全天。 {{ tbia_occurrence_url }}?modified=20240101,20241231
eventDate 以觀測日期查詢。格式 YYYY-MM-DD；單值查詢該日起的資料，區間以逗號分隔，包含起訖日期。 {{ tbia_occurrence_url }}?eventDate=2022-01-01
year 以觀測年查詢。可用範圍為 1700 至今年；單值表示該年起，區間以逗號分隔，包含起訖年。 {{ tbia_occurrence_url }}?year=2022
month 以觀測月查詢。可用範圍 1 至 12；單值表示該月起，區間以逗號分隔，包含起訖月。 {{ tbia_occurrence_url }}?month=01
taibifModifiedDate 以 TaiBIF 資料解讀／處理日期查詢。沿用舊格式 YYYY-MM-DD；單值表示該日起，區間以逗號分隔。不同於 modified 的 YYYYMMDD 單日查詢。 {{ tbia_occurrence_url }}?taibifModifiedDate=2022-01-01

地理資訊參數

名稱 備註 範例
boundedBy 以四邊形座標範圍查詢。格式：最小經度,最小緯度,最大經度,最大緯度。沿用既有公開網格，邊界結果可能包含同一網格內的其他位置。 {{ tbia_occurrence_url }}?boundedBy=121.1,22.1,121.2,22.2
coordinateUncertaintyInMeters 取得座標誤差（含以下）之物種出現紀錄資料，單位為公尺 {{ tbia_occurrence_url }}?coordinateUncertaintyInMeters=100
country 以國家名稱查詢 {{ tbia_occurrence_url }}?country=Taiwan
county 需要使用控制詞彙進行查詢，請參閱下方「控制詞彙查詢參數對照表」 {{ tbia_occurrence_url }}?county=臺北市

回傳欄位說明

名稱 類型 說明
occurrenceID 字串 TaiBIF 物種出現紀錄識別碼。
catalogNumber 字串 典藏機構登錄號。
modified 字串 TaiBIF 資料解讀／處理日期，格式 YYYYMMDD，不是來源紀錄的原始修改日期。
selfProduced 布林值 是否為第一手資料，以 true 或 false 表示，無法判定時為 null。
license 字串 紀錄授權方式：CC0、CC-BY、CC-BY-NC，無法辨識時為 null。
basisOfRecord 字串 紀錄類型，無法對應控制詞彙時為 null。
recordNumber 字串 採集號。
recordedBy 字串 記錄者／採集者。
datasetName 字串 所屬公開資料集名稱，與 TBIA 資料集 API 一致。
datasetID 字串 所屬資料集的 TaiBIF UUID，與 TBIA 資料集 API 一致。
resourceCitationIdentifier 字串 所屬資料集的 GBIF 頁面網址。
associatedMedia 字串 關聯多媒體。
mediaLicense 字串 多媒體授權方式，採用與 license 相同的控制詞彙。
organismQuantity 數值 數量。
organismQuantityType 字串 數量單位。
typeStatus 字串 典藏模式/引證類型。
locality 字串 地區。
verbatimSRS 字串 原始大地基準。
geodeticDatum 字串 大地基準。
coordinateUncertaintyInMeters 數值 以公尺為單位的坐標誤差。
dataGeneralizations 字串 模糊化方式說明。
decimalLatitude 數值 現有公開資料的十進位緯度，不以原始精確座標補值。
decimalLongitude 數值 現有公開資料的十進位經度，不以原始精確座標補值。
countryCode 字串 國家代碼。
county 字串 直轄市或省轄縣市。
year 整數 西元年。
month 整數 月。
day 整數 日。
verbatimScientificName 字串 來源提供的原始物種學名。
scientificName 字串 TaiBIF 現有資料處理流程採用的校定學名。
vernacularName 字串 校定物種俗名。
scientificNameID 字串 TaiBIF 校定物種名稱代碼，使用的分類觀依據 nameAccordingTo。
nameAccordingTo 字串 校定學名的參考來源，例如 TaiCOL 或 GBIF。
taxonRank 字串 鑑定層級。
taxonGroup 字串 TaiBIF 生物類群。
kingdom 字串 界。
phylum 字串 門。
class 字串 綱。
order 字串 目。
family 字串 科。
genus 字串 屬。
originalOccurrenceID 字串 來源提供的原始出現紀錄識別碼。
gbifID 字串 GBIF 出現紀錄識別碼。
establishmentMeans 字串 類群當地原生性
occurrenceStatus 字串 觀測狀態
eventDate 字串 觀測日期，保留原有公開資料的日期表示。
coordinatePrecision 浮點數 既有公開座標的精度或模糊化程度。
country 字串 國家
habitatReserve 字串 紀錄位置對應的自然生態保護區。
wildlifeReserve 字串 紀錄位置對應的野生動物保護區。
datasetShortName 字串 資料集短名稱。
gbifDatasetID 字串 GBIF 資料集識別碼。
issue 字串 資料處理時發現的問題；多個值以 | 分隔。
