{% trans "認證辦法" %}

每期工作坊皆有5項課程指定作業，包含2項初階作業及3項進階作業。 完成課程指定作業，並於課後一個月內繳交至線上作業繳交表單， 經各項主題課程講師評分後，分數達標即可獲得TaiBIF課程認證證書。

{% trans "指定作業項目（將持續更新）" %}

初階作業

  • DwC 資料欄位對應 + Sampling Event 資料集整理
  • 資料集上傳TaiBIF test IPT

進階作業

  • openRefine 資料清理
  • 開放資料下載
  • DMP 資料管理方案規劃

{% trans "作業評核標準" %}

初階認證

初階作業每項滿分20分，累計各項作業總分達25分即通過。

進階認證

此認證須完成包含初階作業在內所有作業，每項滿分20分 (DMP 資料管理方案滿分30分)，累計各項作業總分達70分即通過；40分以上未達70分者則給予初階認證。
