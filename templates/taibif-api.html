說明 Usage

最後修改：2025/01/24

使用規範

本 API 採「政府資料開放授權條款－第1版」

格式說明

  • 服務網址格式為 https://portal.taibif.tw/api/v3/{類型}?{參數}
  • 使用範例
    類型 說明 範例
    occurrence 查詢物種的出現紀錄 https://portal.taibif.tw/api/v3/occurrence?{參數}
    dataset 查詢資料集 https://portal.taibif.tw/api/v3/dataset?{參數}
    publisher 查詢資料集的發布單位 https://portal.taibif.tw/api/v3/publisher?{參數}
  • 回傳範例（JSON 格式）
                                {
                                "status": {
                                    "code": 回傳狀態代碼,
                                    "message": 回傳狀態說明
                                },
                                "params": {查詢參數字典},
                                "count": 結果筆數,
                                "data": [結果陣列]
                            }

分頁參數說明

參數 說明 範例
rows每頁回傳筆數。預設為 10 筆，1000 筆為上限 /api/v3/occurrence?rows=10
offset 起始回傳資料位置。預設為 0 /api/v3/occurrence?offset=0
如有建議或額外需求，歡迎聯絡我們

出現紀錄 Occurrence API

查詢參數說明

  • 物種資訊
    名稱 備註 範例
    originalOccurrenceID 以資料提供者之物種出現紀錄 ID 查詢指定的出現紀錄資料 /api/v3/occurrence?originalOccurrenceID=b92ca705-d4de-4319-820c-1bbad1079844
    taibifOccurrenceID 以本網站之物種出現紀錄 ID 查詢指定的出現紀錄資料 /api/v3/occurrence?taibifOccurrenceID=797223337
    basisOfRecord 以出現紀錄類型查詢。需要以控制詞彙查詢，控制詞彙如下：材料實體, 保存標本, 化石標本, 活體標本, 人為觀測, 材料樣本, 機器觀測, 調查活動, 名錄/分類群, 出現紀錄, 文獻紀錄 /api/v3/occurrence?basisOfRecord=人為觀測
    taibifScientificName 以本網站對應物種 backbone 之學名查詢，物種 backbone 包含 TaiCOL 以及 GBIF /api/v3/occurrence?taibifScientificName=Muntiacus reevesi micrurus (Sclater, 1875)
    taxonRank 以物種分類階層查詢，包含 kingdom, phylum, class, order, family, genus, species /api/v3/occurrence?taxonRank=species
    kingdom 物種分類階層之界。需要用控制詞彙查詢，控制詞彙如下：Animalia, Archaea, Bacteria, Chromista, Fungi, Plantae, Protozoa, Viruses /api/v3/occurrence?kingdom=Plantae
    phylum 物種分類階層之門 /api/v3/occurrence?phylum=Tracheophyta
    class 物種分類階層之綱 /api/v3/occurrence?class=Elasmobranchii
    order 物種分類階層之目 /api/v3/occurrence?order=Magnoliales
    family 物種分類階層之科 /api/v3/occurrence?family=Erebidae
    genus 物種分類階層之屬 /api/v3/occurrence?genus=Grevillea
    taxonGroup 以本網站分類之物種類群查詢。需要用控制詞彙查詢，控制詞彙如下：Fishes, Insects, Amphibia, Reptiles, Birds, Mammals, Others, Viruses, Plants, Fungi, Bacteria, Archaea /api/v3/occurrence?taxonGroup=Fishes
    establishmentMeans 以原生或引入定義評估查詢。需要用控制詞彙查詢，控制詞彙如下：原生, 原生：再引進, 引進（外來、非原生、非原住）, 引進（協助拓殖）, 流浪的, 不確定的（未知、隱源性） /api/v3/occurrence?establishmentMeans=原生
    occurrenceStatus 以出現狀態查詢。需要用控制詞彙查詢，控制詞彙如下：出現, 未出現 /api/v3/occurrence?occurrenceStatus=出現
  • 時間資訊
    名稱 備註 範例
    eventDate 以觀測日期查詢。日期格式包含 yyyy-mm-dd（單一日期）以及 yyyy-mm-dd,yyyy-mm-dd（區間日期） /api/v3/occurrence?eventDate=2022-01-01
    year 以觀測年查詢。格式包含 yyyy（單一年份）以及 yyyy,yyyy（區間年份） /api/v3/occurrence?year=2022
    month 以觀測月查詢。格式包含 mm（單一月份）以及 mm,mm（區間月份） /api/v3/occurrence?month=01
    taibifModifiedDate 以本網站資料更新日期查詢。日期格式包含 yyyy-mm-dd（單一日期）以及 yyyy-mm-dd,yyyy-mm-dd（區間日期） /api/v3/occurrence?taibifModifiedDate=2022-01-01
  • 地理資訊
    名稱 備註 範例
    boundedBy 取得指定四邊形座標範圍內物種出現紀錄資料，格式為：最小經度,最小緯度,最大經度,最大緯度 /api/v3/occurrence?boundedBy=121.1,22.1,121.2,22.2
    coordinateUncertaintyInMeters 取得座標誤差（含以下）之物種出現紀錄資料，單位為公尺 /api/v3/occurrence?coordinateUncertaintyInMeters=100
    country 以國家名稱查詢 /api/v3/occurrence?country=Taiwan
    county 以臺灣縣市名稱查詢。需要用控制詞彙查詢，控制詞彙如下： Keelung City, New Taipei City, Taipei City, Taoyuan City, Hsinchu County, Hsinchu City, Miaoli County, Taichung City, Changhua County, Nantou County, Yunlin County, Chiayi County, Tainan City, Kaohsiung City, Pingtung County, Yilan County, Hualien County, Taitung County, Penghu County, Kinmen County, Lienchiang County /api/v3/occurrence?county=Taipei City
  • 資料集資訊
    名稱 備註 範例
    datasetName 以資料集名稱查詢 /api/v3/occurrence?datasetName=Sea turtle sightings in Taiwan | 台灣海龜目擊紀錄
    taibifDatasetID 以本網站之資料集 ID 查詢指定的出現紀錄資料 /api/v3/occurrence?taibifDatasetID=2e0a47e6-07f2-4b3d-9ed7-cfac5abccbb2
  • 其他資訊
    名稱 備註 範例
    selfProduced 以是否透過 TaiBIF IPT 上傳查詢。True 為透過 TaiBIF IPT 上傳之出現紀錄；False 為介接 GBIF 上點位為臺灣之出現紀錄 /api/v3/occurrence?selfProduced=True
    license 以出現紀錄授權方式查詢。需要用控制詞彙查詢，控制詞彙如下：CC0, CC-BY, CC-BY-NC, NA /api/v3/occurrence?license=CC0

回傳欄位說明

  • 物種資訊
    名稱 類型 說明
    gbifID 字串 GBIF 資料辨識碼
    originalOccurrenceID 字串 資料發布者提供的資料辨識碼
    taibifOccurrenceID 字串 TaiBIF 資料辨識碼
    basisOfRecord 字串 紀錄類型
    originalScientificName 字串 資料發布者提供的物種學名
    taibifScientificName 字串 TaiBIF 轉譯後的物種學名
    taxonRank 字串 物種分類階層
    scientificNameID 字串 物種名稱代碼，使用的分類觀依據 taxonBackbone
    taxonBackbone 字串 物種 Backbone 來源
    vernacularName 字串 物種中文俗名
    kingdom 字串 界
    phylum 字串 門
    class 字串 綱
    order 字串 目
    family 字串 科
    genus 字串 屬
    taxonGroup 字串 分類階層
    establishmentMeans 字串 類群當地原生性
    occurrenceStatus 字串 觀測狀態
  • 時間資訊
    名稱 類型 說明
    eventDate 字串 觀測日期
    year 數字 觀測年
    month 數字 觀測月
    day 數字 觀測日
    taibifModifiedDate 字串 TaiBIF 更新日期
  • 地理資訊
    名稱 類型 說明
    geodeticDatum 字串 座標系統
    verbatimSRS 字串 空間參考系統
    decimalLongitude 浮點數 經度
    decimalLatitude 浮點數 緯度
    coordinatePrecision 浮點數 座標模糊化程度
    coordinateUncertaintyInMeters 浮點數 原始座標誤差（公尺）
    dataGeneralizations 字串 座標模糊化方式
    countryCode 字串 國家代碼
    country 字串 國家
    county 字串 臺灣縣市
    locality 字串 出現地
    habitatReserve 字串 自然生態保護區
    wildlifeReserve 字串 野生動物保護區
  • 資料集資訊
    名稱 類型 說明
    datasetName 字串 資料集名稱
    datasetShortName 字串 資料集短名稱
    taibifDatasetID 字串 TaiBIF 資料集 ID
    gbifDatasetID 字串 GBIF 資料集 ID
  • 其他資訊
    名稱 類型 說明
    selfProduced 布林值 是否為 TaiBIF IPT 來源的資料
    license 字串 出現紀錄授權方式
    typeStatus 字串 標本模式
    recordedBy 字串 記錄（採集）者
    recordNumber 字串 採集號
    catalogNumber 字串 館藏號
    organismQuantity 數字 數量
    organismQuantityType 字串 數量單位
    associatedMedia 字串 多媒體連結
    mediaLicense 字串 多媒體授權方式
    issue 字串 資料問題

資料集 Dataset API

查詢參數說明

名稱 備註 範例
datasetName 以資料集名稱查詢 /api/v3/dataset?datasetName=Sea turtle sightings in Taiwan | 台灣海龜目擊紀錄
taibifDatasetID 以本網站之資料集 ID 查詢指定的出現紀錄資料 /api/v3/dataset?taibifDatasetID=2e0a47e6-07f2-4b3d-9ed7-cfac5abccbb2
publisherID 以本網站之發布單位 ID 查詢指定的出現紀錄資料 /api/v3/dataset?publisherID=e506ec0c-b3c5-4c3d-ae69-ebc56596fc52
publisherName 以發布單位名稱查詢 /api/v3/dataset?publisherName=TurtleSpot Taiwan 海龜點點名
author 以發布者查詢
publicationDate 以資料集發布日期查詢。日期格式包含 yyyy-mm-dd（單一日期）以及 yyyy-mm-dd,yyyy-mm-dd（區間日期） /api/v3/dataset?publicationDate=2022-01-01
datasetModifiedDate 以資料集更新日期查詢。日期格式包含 yyyy-mm-dd（單一日期）以及 yyyy-mm-dd,yyyy-mm-dd（區間日期） /api/v3/dataset?datasetModifiedDate=2022-01-01
gbifDatasetID 以 GBIF 資料集 ID 查詢指定的出現紀錄資料 /api/v3/dataset?gbifDatasetID=336b6790-062f-407f-a783-2f1d8874e6c3
core 以資料集核心類型查詢。需要用控制詞彙查詢，控制詞彙如下：SAMPLINGEVENT, OCCURRENCE, CHECKLIST, METADATA /api/v3/dataset?core=SAMPLINGEVENT
license 以出現紀錄授權方式查詢。需要用控制詞彙查詢，控制詞彙如下：CC0, CC-BY, CC-BY-NC, NA /api/v3/dataset?license=CC0
source 以資料集來源查詢。需要用控制詞彙查詢，控制詞彙如下：TaiBIF IPT, GBIF /api/v3/dataset?source=TaiBIF IPT

回傳欄位說明

名稱 類型 說明
datasetName 字串 資料集名稱
taibifDatasetID 字串 TaiBIF 資料集 ID
publisherID 字串 發布單位 ID
publisherName 字串 發布單位名稱
author 字串 發布者
datasetShortName 字串 資料集在 TaiBIF IPT 上的簡稱
publicationDate 字串 資料集發布日期
datasetModifiedDate 字串 資料集更新日期
gbifDatasetID 字串 GBIF 資料集 ID
core 字串 資料集核心類型
license 字串 出現紀錄授權方式
doi 字串 數位物件識別號（Digital Object Identifier）
numberRecord 數字 資料筆數
numberOccurrence 數字 出現紀錄筆數
source 字串 資料集來源

發布單位 Publisher API

查詢參數說明

名稱 備註 範例
publisherID 以本網站之發布單位 ID 查詢指定的出現紀錄資料 /api/v3/publisher?publisherID=e506ec0c-b3c5-4c3d-ae69-ebc56596fc52
publisherName 以發布單位名稱查詢 /api/v3/publisher?publisherName=TurtleSpot Taiwan 海龜點點名
countryCode 以發布單位國家代碼查詢。需使用 ISO 3166-1 兩碼 /api/v3/publisher?countryCode=TW

回傳欄位說明

名稱 類型 說明
publisherID 字串 發布單位 ID
publisherName 字串 發布單位名稱
description 字串 發布單位描述
administrativeContact 字串 發布單位聯絡人
technicalContact 字串 技術聯絡人
countryCode 字串 發布單位國家代碼
countryOrArea 字串 發布單位國家
installations 字串 裝置
