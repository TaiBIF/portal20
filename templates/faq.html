資料發布問題諮詢

TaiBIF 提供任何生物多樣性資料發布的諮詢服務及協助，常見問題可先參考資料集發布常見問題， 若沒有找到您需要的解答，可加入FB社團：TaiBIF/GBIF 資料發布問題討論並發問， 或進一步聯繫我們。

資料論文合作

TaiBIF每年皆有固定經費來贊助與生物多樣性相關之主題的資料論文發表，欲知詳情如合作模式與適用條件，歡迎聯繫我們。

相關條件：

  1. 須將資料集上傳至TaiBIF 和 GBIF，上傳流程請參照開放資料流程
  2. 須將TaiBIF 團隊中至少一位成員列為共同作者（該成員將可協助資料發布）
  3. 須於致謝（Acknowledgement）中提及 Taiwan Biodiversity Information Facility, TaiBIF

要如何註冊成為資料發布單位？

原則上註冊成為資料發布單位（GBIF data publisher），可以組織、團體、公司企業、公部門、大專院校系所為單位，不建議以個人名義註冊成為資料發布單位，步驟如下：

  • a. 先至GBIF 網頁填寫註冊申請表單（Become a publisher），須以英文為主
  • b. 等待3-5個工作天，經由GBIF秘書處及委員審核核可後，會收到註冊成功確認信
  • c. 請將註冊成功確認信裡附上的組織密碼（token），轉寄給TaiBIF helpdesk
  • d. 由TaiBIF將貴單位匯入IPT組織清單中，完成後即可以貴單位名義發布資料集

資料發布的流程為何？

詳細的步驟與說明，請見開放資料流程，點選每個步驟的按鈕即可檢視指引文件。

我已經檢核好資料，也在 IPT 上成功發布，為什麼在 GBIF 看不到最新的資料筆數？

有幾種可能原因：

  • a. 資料筆數過大，GBIF 需要時間更新，可以過一兩天後再確認，如果過三天還是沒有，歡迎聯繫 TaiBIF。
  • b. 更新資料集時，換掉超過 50% 的舊資料 ID，導致 GBIF 暫停此次更新。需要聯繫 TaiBIF，或是自己換回原本的資料ID再重新上傳（盡量不要更改已發布的資料ID）。
  • c. 若資料集的 Core 為調查活動 Sampling Event，可能是 Occurrence Extension 沒有對應到 core 的 eventID，所以系統無法順利將 core 和 extension 連結，請再次檢查每筆 occurrence 是否都有對應到 eventID。

我想新增資料，需要重新上傳整個檔案嗎？

以下兩點需要特別注意：

  • a. 不需要，只要上傳新的檔案就好，但要注意欄位和舊資料一致
  • b. 如果必須整個檔案上傳，不要換掉超過 50% 的舊資料 ID (eventID, occurrence ID 等)，超過比例會導致 GBIF 暫停此次更新。

資料只能選一種授權類型嗎？

資料集、每筆出現紀錄、多媒體檔案的授權類型都可以不同。

  • 資料集 在 IPT 中的 metadata 中定義
  • 出現紀錄 用 core/extension 中的 DwC 欄位 license 定義
  • 多媒體檔案 用 extension Simple Multimedia 中的欄位 license 定義

如果資料用一樣的調查方法收集，但計畫隨著不同年份有所修改，建議如何填寫？

建議持續更新成一個更大的資料集，並修改詮釋資料（metadata）的年份範圍（temporal coverage），保持資料集是活的，也能提高資料的能見度和再利用性。

如果想將發布過的資料集換發布單位，要怎麼處理？

如果已發布並註冊到 GBIF.org，則無法自己更改發布單位，請聯繫 TaiBIF 協助處理。

IPT上的詮釋資料 Metadata 怎麼寫？

填寫的說明和範例參考，請見：詮釋資料(範本)。

我能自己安裝 IPT 嗎？

可以自己部署，程式碼全是開源的，但完全不建議，因為需要一定技術力、花費部署以及維護成本。如果要發布資料到 GBIF 還會需要與 GBIF 秘書處聯繫來設定串連。

TaiBIF 目前是全亞洲唯一個通過 GBIF 認證的資料託管中心（Data-hosting center），提供及維運 IPT 相關服務。

我已經發布了資料集到GBIF，想改變資料集類型可以嗎？

可以！在IPT上把 Mapping 過的資料檔案刪掉，即可於詮釋資料(metadata)修改資料集類型，然後再重新 Mapping資料檔案並publish。
