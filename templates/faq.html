{% trans "我已經檢核好資料，也在 IPT 上成功發布，為什麼在 GBIF 看不到最新的資料筆數？" %}

{% trans "有幾種可能原因：" %}

  1. {% trans "資料筆數過大" %}{% trans "，GBIF 需要時間更新，可以過一兩天後再確認，如果過三天還是沒有，歡迎" %}{% trans "聯繫 TaiBIF" %}。
  2. {% trans "更新資料集時，" %}{% trans "換掉超過 50% 的舊資料 ID" %}{% trans "，導致 GBIF 暫停此次更新。需要聯繫 TaiBIF，或是自己換回原本的資料ID再重新上傳（盡量不要更改已發布的資料ID）。" %}
  3. {% trans "若資料集的 Core 為調查活動 Sampling Event，可能是" %} {% trans "Occurrence Extension 沒有對應到 core 的 eventID" %}{% trans "，所以系統無法順利將 core 和 extension 連結，請再次檢查每筆 occurrence 是否都有對應到 eventID。" %}

{% trans "我想新增資料，需要重新上傳整個檔案嗎？" %}

{% trans "以下兩點需要特別注意：" %}

  1. {% trans "不需要" %}{% trans "，只要上傳新的檔案就好，但要注意" %}{% trans "欄位和舊資料一致" %}
  2. {% trans "如果必須整個檔案上傳，" %}{% trans "不要換掉超過 50% 的舊資料 ID" %} {% trans "(eventID, occurrence ID 等)，超過比例會導致 GBIF 暫停此次更新。" %}

{% trans "資料只能選一種授權類型嗎？" %}

資料集、每筆出現紀錄、多媒體檔案的授權類型{% trans "都可以不同" %}。

  • {% trans "資料集" %} {% trans "在 IPT 中的 metadata 中定義" %}
  • {% trans "出現紀錄" %} {% trans "用 core/extension 中的 DwC 欄位 license 定義" %}
  • {% trans "多媒體檔案" %} {% trans "用 extension Simple Multimedia 中的欄位 license 定義" %}
