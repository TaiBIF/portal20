{% trans "什麼是資料論文？" %}

{% trans "資料論文（Data paper）是一個透過同儕審查（Peer reviewed）的論文形式發表於相關的期刊上。" %} {% trans "與傳統的研究論文不同，資料論文不提假設和結論，" %} {% trans "內容主要為描述作者所開放的資料集相關資訊，" %} {% trans "包含如何產生及收集資料、資料類型、涵蓋的物種、資料開放於何處及此資料集背景資訊（Metadata）等等，" %} {% trans "透過作者於此資料集所開放的資料授權方式，可作為日後學術論文應用其資料時所引用的依據。" %}


{% trans "發表資料論文的好處與目的包括：" %}

  • {% trans "提供可引用的期刊出版物（如DOI），為資料發布者帶來學術上的認可" %}
  • {% trans "人類可讀的結構化資料描述" %}
  • {% trans "增加您發布的資料資源的可見性、可用性和可信度" %}
  • {% trans "更有效地追蹤您發布的資料的使用情況和引用情況" %}

{% trans "資料論文合作" %}

TaiBIF每年皆有固定經費來贊助與生物多樣性相關之主題的資料論文發表，欲知詳情如合作模式與適用條件，歡迎聯繫我們。

TaiBIF 可提供的合作項目

  1. 開放資料流程協助或諮詢服務（包含協助清理及開放資料）
  2. 為論文草稿提供撰寫建議
  3. 建議適合投稿的資料期刊
  4. 資助論文發表費（需符合補助條件）

發表費補助條件

  1. 須將資料集上傳至TaiBIF 和 GBIF，上傳流程請參照開放資料流程
  2. 須將有協助開放資料的TaiBIF成員或TaiBIF資料清理協作者列為共同作者
  3. 須於致謝（Acknowledgement）中提及 Taiwan Biodiversity Information Facility, TaiBIF及經費提供單位（國科會）

發表費優先補助對象

  1. 資料可填補台灣生物多樣性資料空缺者
  2. 資料符合 GBIF New Data Model 案例
  3. 以非營利組織及國內經費有限之學術研究單位優先補助對象
